# exe-network-blocker

# 🔒 Απομόνωση Δικτύου για setup.exe

Αυτό το εργαλείο απομονώνει προσωρινά από το δίκτυο ένα αρχείο `setup.exe`, **χωρίς να επηρεάζει τη σύνδεση του υπόλοιπου υπολογιστή**. Είναι ιδανικό για εγκαταστάσεις προγραμμάτων όπως το AutoCAD, που ενδέχεται να επιχειρούν αυτόματες ενημερώσεις ή να συνδεθούν στο internet.

## ⚙️ Πώς λειτουργεί

1. Δημιουργεί έναν προσωρινό **κανόνα στο Windows Firewall** που μπλοκάρει την έξοδο δικτύου του `setup.exe`.
2. Εκτελεί το `setup.exe`.
3. Μετά την έξοδο του προγράμματος, **αφαιρεί τον κανόνα**.

## 🖥 Διαθέσιμο ως:

- ✅ **Python script** – `script.py`
- ✅ **Έτοιμο εκτελέσιμο αρχείο (.exe)** – χωρίς να χρειάζεται Python!

## 🚀 Τρόποι εκτέλεσης

### ✅ Επιλογή 1: Χρήση του `.exe` (χωρίς Python)

1. Κατέβασε το `setup.exe` από τα [Releases](./releases).
2. Κάνε δεξί κλικ → **"Εκτέλεση ως διαχειριστής"**.

### 🐍 Επιλογή 2: Εκτέλεση του Python script

1. Βεβαιώσου ότι έχεις εγκαταστήσει Python 3.
2. Τρέξε από τερματικό (ως διαχειριστής):

```bash
python3 script.py
